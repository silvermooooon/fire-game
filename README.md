# 花火 · 双人联机版

一款本地运行的双人合作网页桌游。玩家能看见搭档的手牌，却看不见自己的牌面；两人需要用有限的提示，把五种颜色分别按 `1 → 5` 的顺序打出。

> 非官方学习实现，不包含原作卡面资源；页面插画与卡背均为本项目专门生成的原创美术。

## 本地运行

需要 Node.js 20.9 或更高版本。

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。开发服务会监听所有本地网络接口；同一局域网内的另一台设备可使用终端显示的 Network 地址访问（首次使用时可能需要允许 Windows 防火墙访问）。

创建者填写称呼并创建房间，将五位房间号或邀请链接发给另一位玩家。若要在同一台电脑上模拟两位玩家，建议使用两个不同浏览器或一个普通窗口加一个无痕窗口。

房间、牌局和聊天记录当前只保存在 Node.js 进程内存中；刷新或重新打开页面可以凭本浏览器保存的会话恢复座位，也可以主动“离开”来释放座位。停止或重启开发服务会清空所有房间。

## 已实现

- 五色标准牌组：每色 `1×3、2×2、3×2、4×2、5×1`
- 双人各五张手牌，自己牌面的真实颜色与数字不会下发到自己的客户端
- 创建房间、五位房间号、局域网邀请链接、主动离开与满房拦截
- 实时房间状态、在线状态、断线自动重连
- 服务端权威验证的提示、出牌、弃牌、补牌、计分和终局
- 正向及排除线索记忆，线索绑定具体牌而不是会移动的位置
- 最后一张牌后的完整最终轮
- 房间内文字聊天与独立牌局记录
- 弃牌堆统计、规则说明、结束结算与房主再来一局
- 桌面和手机响应式界面、键盘焦点与减少动态效果偏好
- 桌面横版、手机竖版游戏桌背景与专属漆金卡背
- 点卡片打开统一操作框；桌面也可右键队友牌快速选择正式提示
- 自己的牌按线索渐进显现：只知颜色时显示彩色无数字，只知数字时显示中性牌面与角标
- 搭档明牌固定显示“色已知 / 数已知 / 已排除”记忆印记，提示框会提醒重复提示仍会消耗筹码
- 五色真实卡牌扇形花火区、常驻弃牌漆盘，以及牌堆、提示筹码和失误引线桌面道具
- 移动端浮动聊天气泡与未读提醒；桌面聊天保持侧栏布局并增加未读数
- 发牌、补牌、手牌顺序收拢、出牌、弃牌、提示命中与失败动画
- 成功出牌 `1 → 5` 五级烟火规模，以及带明确原因的失误反馈

局内操作：

- 点队友的一张牌，可在弹框中选择提示这张牌的颜色或数字；仍会按正式规则同时揭示所有匹配牌并消耗 1 枚提示。
- 点自己的一张牌，可在弹框中选择打出或弃牌。手机端使用同一套点击操作，不依赖右键或长按。
- 桌面端右键队友牌会打开同一提示框；盘面上不再保留独立的十个颜色/数字提示按钮。

本作采用当前新版规则中允许“零命中提示”的口径，例如可以提示“你的手牌里没有红色”。自由聊天属于额外房规功能；严格玩法应只通过正式提示交流牌面信息。

## 验证

```bash
npm test
npm run test:smoke
npm run lint
npm run build
```

`test:smoke` 需要本地开发服务已经运行，会模拟两个独立客户端完成“创建 → 加入 → 开局 → 聊天 → 提示 → 弃牌”。

## 实现结构

- Next.js App Router 同时提供页面与房间 API
- 浏览器通过 Server-Sent Events 接收个性化实时快照，通过普通 POST 提交操作
- 单进程内存房间表；无需数据库、账号或外部实时服务
- 每次广播前都按玩家生成私密视图，牌堆顺序和自己的真实牌面不会进入前端

核心规则在 `src/lib/hanabi.ts`，房间和连接管理在 `src/lib/room-store.ts`，前端在 `src/components/hanabi-app.tsx`。
